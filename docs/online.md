# Онлайн-проверка «Берік Тұлға»

Основное приложение написано на Flutter. Expo Go запускает приложения React Native и не может открыть этот проект. На Android Flutter проверяется установкой APK, на iPhone — отдельной подписанной iOS-сборкой; подготовка описана в [iphone.md](iphone.md).

## Подключение Supabase

1. Для нового проекта Supabase выполните все шесть файлов из `supabase/migrations/` по порядку. В уже подключённом проекте миграции `202610070004_territory_capture.sql` и `202610070005_territory_restrictions.sql` выполнены 7 октября 2026; повторно запускать их не нужно. Они добавляют серверный захват и 418 исключений из карты OSM. Миграция `202610080006_trail_segment_closure.sql` применена 8 октября: минимум 100 м, замыкание на любом участке линии и клетки по центрам внутри контура; повторно запускать её не нужно.
2. Включите Email Auth. В Authentication → Sign In / Providers выключите `Allow new users to sign up`. Вход выполняется по email и паролю существующего пользователя; самостоятельной регистрации в приложении нет.
3. Скопируйте `.env.example` в `.env`, заполните `SUPABASE_URL`, `SUPABASE_ANON_KEY` публичным publishable/anon key и установите `OFFLINE_ONLY=false`. Secret/service-role key не используется. `.env` исключён из Git.
4. Проверьте настройки и доступность Auth:

```powershell
.\scripts\check-online.ps1 -Probe
```

Скрипт не выводит ключ и не отправляет SMS или email. Он проверяет доступ к Auth и показывает, закрыта ли самостоятельная регистрация, но не заменяет проверку входа по паролю и синхронизации.

5. Подключите Android-телефон и запустите:

```powershell
.\scripts\run.ps1 -Target android -Online
```

Для браузерного просмотра можно использовать `-Target web -Online`; шагомер телефона проверяется на физическом устройстве.

6. На стартовом экране выберите «Войти» / «Кіру», введите email и пароль, выданные администратором. Затем заполните профиль и вступите в команду. Если ранее был выбран локальный или демо-режим, сначала выйдите через вкладку профиля. Запишите короткую прогулку, завершите её и проверьте свою запись в `activity_sessions` и точки в `activity_points`.

## Как создавать аккаунты пользователям

В [Supabase Authentication → Users](https://supabase.com/dashboard/project/izkdjszrkvbzqtyudbje/auth/users) откройте **Add user → Create new user**. Заполните **Email address** и **User Password**, оставьте **Auto confirm user?** включённым и нажмите **Create user**. Этот email служит логином. Форма создаёт подтверждённый аккаунт без отправки письма, поэтому собственный SMTP для такого входа не требуется. Уведомление `Confirm email` в настройках провайдера можно оставить включённым.

Создавайте именно Auth-пользователя: триггер сам добавит его профиль в `public.users`. При первом входе пользователь заполняет имя и username профиля, затем вступает в команду. Username профиля служит именем участника; для входа используется email. Пароли не записываются в таблицу профилей или настройки приложения. Восстановление доступа пока выполняет администратор через управление пользователем в Supabase.

## Сборка для установки

Android release теперь сохраняет разрешение `INTERNET` из основного манифеста. Скрипт проверяет конфигурацию и доступ к Auth, собирает release APK и сохраняет его вместе с SHA-256 в `artifacts/berik-tulga-online.apk`:

```powershell
.\scripts\build-online.ps1
```

На Mac те же настройки нужно явно передать iOS-сборке:

```bash
flutter run --release -d <iphone-id> --dart-define-from-file=.env
```

Текущая GitHub-сборка iPhone не получает `.env`; без передачи конфигурации она создаст офлайн-версию.

Карта города по-прежнему встроена и не требует сети. Локальные и демо-прогулки остаются на устройстве. Облачные RPC используются после входа в аккаунт. Замкните непрерывный контур: не менее 100 м пути и 1 000 м², вернитесь к любой точке пройденной линии на расстояние до 25 м или пересеките её. Сервер захватит доступные клетки с центрами внутри контура; в результате и истории появится площадь. Во время отсутствия сети результат остаётся в очереди и обновляется после синхронизации. Локальная прогулка без аккаунта не меняет общую территорию; демо рассчитывает отдельные тестовые клетки. XP и соревновательные награды пока отключены.

Проект `berik-tulga` (`izkdjszrkvbzqtyudbje`) подключён 6 октября 2026 и обновлён 8 октября. Все шесть миграций выполнены; клиент не может изменять владельцев клеток, HP, события и площадь напрямую. `.env` содержит публичный ключ проекта, `OFFLINE_ONLY=false`. Онлайн APK версии 0.1.7+8 подключён к этому проекту; захваченная арена показана сплошной заливкой без сетки, самостоятельная регистрация закрыта. Подробные результаты — в [verification.md](verification.md).

Вход использует [Supabase signInWithPassword](https://supabase.com/docs/reference/dart/auth-signinwithpassword). Письмо, SMS и переход по ссылке для входа не нужны. Платные услуги не подключались. Сборка release подписана текущим тестовым сертификатом проекта для установки поверх предыдущего тестового APK.
