# Берік Тұлға

Flutter-приложение для утренних прогулок в Қызылорде. Версия 0.1.7 исправляет захват коротких контуров и замыкание на любом участке линии; отображает захваченную арену сплошной заливкой без сетки. Замкнутый GPS-контур захватывает территорию и начисляет вычисленную сервером площадь. Сохраняет встроенную карту города, GPS, шагомер, профиль и историю. Онлайн APK подключён к Supabase: вход по email и паролю, профиль, команда и синхронизация прогулок. Аккаунты создаёт владелец проекта в Supabase; самостоятельная регистрация закрыта. Обычная сборка без настроек облака запускается в офлайн-режиме. Готовый APK и инструкция — в [docs/online.md](docs/online.md).

## Запуск

Для iPhone смотрите [инструкцию iOS](docs/iphone.md). На Mac `bash scripts/ios.sh prepare` подготовит конфигурацию и откроет Xcode. Без личного Mac предусмотрена ручная облачная сборка в `.github/workflows/iphone.yml` и установка с Windows через Sideloadly с обычным Apple ID. Эта облачная сборка ещё не запускалась; готового IPA пока нет.

Требуется Flutter 3.47 / Dart 3.13.5 или совместимая версия, Android SDK и JDK 21+. Для iOS нужны macOS, Xcode и устройство с iOS 15+. Android minimum SDK — 26.

```powershell
flutter pub get
flutter run
```

Настоящая карта OpenStreetMap встроена в приложение: 5 669 участков дорог, 45 214 зданий, водоёмы, зелёные зоны и названия. MapLibre читает геометрию, стиль и шрифты из локальных файлов. Интернет и предварительное скачивание не нужны даже при первом запуске. Область карты: 44.72–44.98° N, 65.34–65.70° E; за её пределами GPS продолжает записывать маршрут, но улицы не показаны.

Для реальной прогулки без регистрации выберите «Офлайн серуендеу» / «Прогулка офлайн» на стартовом экране или под БАСТАУ в демо. Нажмите **БАСТАУ**, разрешите GPS и физическую активность, затем начните идти. **АЯҚТАУ** остановит запись и сохранит её в локальную историю. Координаты читаются с устройства; шаги — напрямую с датчика через `pedometer` (Android `TYPE_STEP_COUNTER`, iOS `CMPedometer`). Health Connect и Apple Health не требуются. Локальный режим не отправляет маршрут в Supabase и не участвует в общих рейтингах. Профиль редактируется локально.

Оптимизированный APK собирается командой `flutter build apk --release`. Android release сохраняет разрешение `INTERNET` для онлайн-сборок с Supabase. При стандартном `OFFLINE_ONLY=true` Supabase отключён; офлайн-карта и GPS не используют сетевые ресурсы.

«Демо режимді көру» запускает отдельную симуляцию GPS, шагов и захвата. Нажмите **БАСТАУ** и дождитесь полного контура — примерно 72 секунды после отсчёта. Появятся окрашенные клетки и около 160 756 м². **АЯҚТАУ** сохраняет прогулку с территорией; клетки восстанавливаются после перезапуска. Повторный обход не начисляет ту же площадь заново. Демо никогда не отправляется в Supabase.

На этом компьютере также доступен скрипт, находящий установленный при разработке SDK:

```powershell
.\scripts\run.ps1 -Target web
.\scripts\run.ps1 -Target android -Device emulator-5554
.\scripts\run.ps1 -Target check
```

## Подключение облачных функций

Пошаговая проверка на телефоне: [docs/online.md](docs/online.md). Этот Flutter-проект не запускается в Expo Go; для Expo Go потребуется версия на React Native.

1. Создайте проект Supabase. Выполните SQL-файлы из `supabase/migrations/` **по порядку** через SQL Editor либо `supabase db push` в связанном проекте.
2. В Auth включите Email и отключите `Allow new users to sign up`. Создавайте пользователей через Authentication → Users → Add user → Create new user: укажите email и пароль, оставьте `Auto confirm user?` включённым. В приложении логин — этот email. См. [Password sign-in](https://supabase.com/docs/reference/dart/auth-signinwithpassword).
3. Скопируйте `.env.example` в `.env`. Укажите `OFFLINE_ONLY=false`, URL проекта и **публичный** publishable/anon key. Service-role key в приложение не добавляется. Разрешение `INTERNET` для Android release уже включено.
4. Запустите:

```powershell
.\scripts\check-online.ps1 -Probe
.\scripts\run.ps1 -Target android -Online
```

`.env` исключён из Git и передаётся как настройки сборки. Публичные ключи извлекаются из собранного приложения, поэтому безопасность обеспечивается RLS и серверными RPC, а не секретностью мобильного файла.

Реальный поток: выданные администратором email и пароль → профиль → вступление в «Берік Тұлға» → карта. «Моё местоположение» показывает GPS-маркер. **БАСТАУ** объясняет доступ к геолокации, шагам и фоновому режиму. Счётчик датчика с момента перезагрузки преобразуется в шаги текущей прогулки: первое показание задаёт ноль, последующие дают прирост. Шаги обновляются при каждом событии датчика и сохраняются даже без новых GPS-точек. Если датчик или разрешение недоступны, отображается `—`; шаги не подменяются расчётом из расстояния.

Для iOS проверьте signing в Xcode. Описание доступа к движению (`NSMotionUsageDescription`) и background location уже включены в проект. [Pedometer](https://pub.dev/packages/pedometer), [MapLibre Flutter](https://pub.dev/packages/maplibre_gl).

## Что работает

- Пять вкладок: карта, активность, команда, рейтинг, профиль.
- Казахский, русский и английский; выбранный язык сохраняется.
- Локальный профиль и аватар без регистрации. Онлайн-сборка добавляет вход по паролю, облачный профиль и команду; в офлайн-сборке облако отключено.
- Встроенная векторная карта OpenStreetMap / MapLibre, GPS-маркер, следование за движением и линии по валидным сегментам. В истории весь маршрут помещается в экран.
- Локальная прогулка с настоящим GPS без аккаунта. Демо, локальные и облачные маршруты хранятся отдельно.
- GPS с дистанционным фильтром 5 м и Android-интервалом 5 с. Android foreground service и iOS background location работают только во время явно запущенной прогулки.
- Таймер, расстояние, шаги с датчика телефона, завершение и отдельный экран результата.
- Локальные checkpoints, очередь по пользователю, батчи по 100 точек, повтор каждые 30 с и при возвращении в приложение.
- Незавершённая запись восстанавливается после перезапуска. Можно сохранить её завершением; автоматический запуск GPS после перезапуска отключён.
- Серия дней и базовые локальные достижения. В локальном/демо-режиме команда и общий рейтинг показывают пояснение об ограничении режима; онлайн доступны команда и подготовленный рейтинг без начисления соревновательных наград.
- Сервер повторно проверяет GPS, пересчитывает расстояние и запрещает клиенту менять игровую статистику. Маршруты доступны только владельцу.
- Онлайн-захват при возвращении к любому участку пройденной линии до 25 м или её пересечении: непрерывный контур от 100 м и валидный контур от 1 000 м². Сервер засчитывает клетки с центром внутри контура, исключает запрещённые зоны и записывает события. Площадь пользователя и команды обновляется в той же транзакции.
- Свободная клетка получает 100 HP; замкнутый обход своей команды укрепляет её на 20 HP (до +50 HP за день), противник снимает 20 HP и получает клетку при нуле. Повторные батчи и завершения не повторяют начисления. Карта загружает владение по viewport и обновляется по Realtime-событиям команды.

## Следующие этапы

Захват включён в подключённом Supabase. В локальной прогулке без аккаунта общая территория не начисляется; демо использует отдельный локальный расчёт. Площадь в онлайне приходит только из серверных RPC.

Предстоит реализовать ежедневное ослабление HP, укрепление клетки обычным проходом без контура, XP и рейтинги, серверные достижения, администрирование сезонов, Firebase push и share card. Соревновательные шаги и XP пока не начисляются из непроверенных клиентских значений. Маска региона учитывает встроенные данные OSM о воде, железной дороге и скоростных дорогах; дополнительные запрещённые зоны добавляются администратором.

Облачный вход и SMS-доставка требуют настроенного Supabase. Для GPS и шагомера нужен телефон с разрешениями и датчиком шагов; в браузере шаги недоступны. iOS-сборка не проверяется на Windows. События Android-счётчика могут приходить с задержкой до 10 секунд; шаги до первого показания и ещё не доставленные при завершении события могут не попасть в итог. Качество подсчёта и работа при заблокированном экране требуют проверки на физическом телефоне.

## Проверки

```powershell
flutter analyze
flutter test
flutter test integration_test/walk_test.dart -d emulator-5554
flutter test integration_test/offline_walk_test.dart -d emulator-5554
flutter build apk --debug
flutter build web
npm ci --prefix tools/backend-check
```
